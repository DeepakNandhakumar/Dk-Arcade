# 🎮 Dk Arcade

**One place. Nine ways to play.** A responsive, no-install mini arcade built with vanilla HTML, CSS, and JavaScript.

## Play locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Pick a game and play — no build step, package install, account, or backend required.

## Games
- 🧩 **Sliding Puzzle** — arrange the numbered tiles in order.
- 🍬 **Candy Pop** — match three or more sweets.
- 🃏 **Memory Cards** — find all eight matching pairs.
- 🦖 **Dino Dash** — jump over obstacles and chase your score.
- ✊ **Rock Paper Scissors** — play a best-of-five match against the computer.
- 🐍 **Snake** — eat fruit using arrow keys or WASD; mobile direction buttons are included.
- 🔢 **Sudoku** — fill the grid and check your solution.
- 🔨 **Whack-a-Mole** — hit as many moles as possible in 20 seconds.
- ⚡ **Monster Match** — swap neighboring tiles to score matches.

## Technology
- Semantic HTML
- CSS (responsive layout, custom styling, animations)
- Vanilla JavaScript (game logic and interactions)
- No external runtime dependencies

## Deploy on Vercel
This is a static site. Import **[DeepakNandhakumar/Dk-Arcade](https://github.com/DeepakNandhakumar/Dk-Arcade)** into Vercel and use:
- **Framework Preset:** Other
- **Root Directory:** `./`
- **Build Command:** leave empty
- **Output Directory:** `.`
- **Install Command:** leave empty

Vercel serves the root `index.html` directly. Every game runs in the browser.
