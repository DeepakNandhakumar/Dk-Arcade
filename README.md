## ✨ Project Highlights

- A common landing page to discover all nine games.
- Separate folders for the original game projects and their supporting assets.
- Browser-based gameplay using HTML, CSS, and JavaScript.
- Responsive styling for different screen sizes.
- Deployed as a static website on Vercel.

## 🧰 Technology

- **HTML5** — page structure
- **CSS3** — layout, styling, and responsive presentation
- **JavaScript** — game interactions and logic
- **Vercel** — static site deployment
- **GitHub** — source control and project hosting

## 💻 Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/DeepakNandhakumar/Dk-Arcade.git
   ```
2. Open the downloaded `Dk-Arcade` folder.
3. Open `index.html` in a modern browser, or use a local static server.
4. Choose a game from the arcade.

No package installation or build step is required for the static landing page.

## 🚀 Deployment on Vercel

This project is deployed at **https://dk-arcade.vercel.app/**.

For a static deployment:
- **Framework Preset:** Other
- **Root Directory:** `./`
- **Build Command:** leave empty
- **Output Directory:** `.`
- **Install Command:** leave empty

Connect the GitHub repository to Vercel and deploy the `main` branch. New commits can trigger a new deployment.
